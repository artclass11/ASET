# ASET SignalDesk research

Call the ASET SignalDesk MCP tool when a ticker is requested.

Use provider-returned values only. Do not fill missing fields with estimates unless the user explicitly asks for an independent estimate and it is clearly separated from provider data.

Always report provider name, freshness, and any research flags returned by the tool.

Do not place trades, represent the output as financial advice, or imply that a research flag is an investment recommendation.
